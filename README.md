# The Gilded Room

Salon demo for Sorted Sites. Plum and brass.

- Site: https://the-gilded-room.pages.dev
- Staff portal: https://the-gilded-room.pages.dev/staff
- API: the-gilded-room-api (Cloudflare Worker)
- Database: D1 the-gilded-room-db

Salon-specific features: deposits on colour services, patch test tracking,
and stylist levels (Stylist / Senior / Director) with price surcharges.
