# The Gilded Room

Salon demo for Sorted Sites. Colour-led, light and editorial.

- Site: https://thegildedroom.pages.dev
- Staff portal: https://thegildedroom.pages.dev/staff
- API: the-gilded-room-api (Cloudflare Worker)
- Database: D1 the-gilded-room-db

Salon-specific features: deposits on colour services, patch test tracking,
and stylist levels (Stylist / Senior / Director) with price surcharges.

Note: the pages.dev projects the-gilded-room and gilded-room are earlier
imports that never received webhooks and are now dead. thegildedroom is live.
